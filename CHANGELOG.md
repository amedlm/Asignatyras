## [No publicado]

### Añadido
- Estructura inicial del repositorio migrada desde el aula virtual Moodle.
- Carpeta `programa/` con `cronograma.md`, `competencias.md`, `biblioteca.bib` y plantilla `guia-docente.md`.
- Carpeta `unidades/` con README de las siete unidades temáticas (u1–u7).
- Carpeta `endpoints-sparql/` con consultas de ejemplo para Wikidata y DBpedia.
- Carpeta `classroom/` con instrucciones para estudiantes y plantillas para P1-RDF y P3-SPARQL.
- Carpeta `recursos/` con `enlaces.md` y `glosario.md`.
- Workflows de GitHub Actions: `validar-owl.yml` (robot + HermiT) y `validar-sparql.yml` (Apache Jena Fuseki).
